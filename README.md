LevelUp is a Java web application originally developed in 2021 for the TSW exam as an e-commerce platform to sell online courses built with JSP, Servlets, and Apache Tomcat, backed 
by a MySQL database. In 2026, the project was revived from a non-functional state, made
buildable and testable again, and used as the target for applying the dependability techniques
covered by the course: "Software Dependability"
